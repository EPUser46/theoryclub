# Cornell Theory Club

Welcome to the Cornell Theory Club website repository!

## About

The Cornell Theory Club is a community of students passionate about theoretical computer science. We explore cutting-edge research in algorithms, complexity theory, cryptography, quantum computing, and more.

## Meeting Information

**Weekly Meetings: Wednesdays at 5:00 PM**

All students are welcome, regardless of experience level!

## Website Structure

The website is styled after the Cornell Physics Wiki format (clean Jekyll Minima style with custom navigation and dropdowns):

- `index.html` - Homepage with welcome message, meeting info, club photo, topics highlights, and upcoming talks spotlight
- `schedule.html` - Full Spring 2026 talk schedule with search filtering and interactive speaker bio/abstract modals
- `leadership.html` - Executive board officers and faculty advisor directory
- `about.html` - Club mission, meeting format, topics, mathematical prerequisites, and FAQs
- `assets/css/main.css` - Main stylesheet matching the Cornell Physics Wiki design system

### Local Preview

To view the website locally:

1. Open `index.html` directly in your web browser, or
2. Start a local HTTP server:
   ```bash
   python3 -m http.server 8080
   ```
   Then visit `http://localhost:8080`
