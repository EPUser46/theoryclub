# Cornell Theory Club

Welcome to the Cornell Theory Club website repository!

## About

The Cornell Theory Club is a community of students passionate about theoretical computer science. We explore cutting-edge research in algorithms, complexity theory, cryptography, quantum computing, and more.

## Meeting Information

**Weekly Meetings: Wednesdays at 5:00 PM**

All students are welcome, regardless of experience level!

## Website

The website is available in `index.html`. To view it locally:

1. Open `index.html` directly in your web browser, or
2. Start a local server:
   ```bash
   python3 -m http.server 8080
   ```
   Then visit `http://localhost:8080/index.html`
